## Features / Características
- **48 Randomized Locations (48 Ubicaciones Aleatorias):**
  - 2 Starting Functions (`Crash()`, `Breach()`)
  - 14 Absorbed Functions across Goldwalk, Highrise, Fairview, and Canals
  - 4 Bosses (`Sybil Reisz`, `The Spine`, `Asher & Grant`, `Royce Bracket`)
  - 28 User Level Up checks (`Level 2` through `Level 15`, Option A & B)
- **Progression & Transportation Keys:**
  - `Motorcycle Key`, `Skyway Ferry Ticket`, and `Canal Boat Key`
  - Configurable `vehicle_keys_mode` in YAML (`early_items`, `start_with_keys`, or `full_random`) to ensure smooth solo and multiworld progression.
- **Goals:**
  - `royce`: Defeat Royce Bracket at the end of the game.
  - `all_functions`: Collect all 16 Functions.

## Quick Installation 
See the full [Setup Guide](SETUP_GUIDE.md) for detailed instructions.

1. Download **`transistor.apworld`** and **`TransistorArchipelago-Client.zip`** from the [Releases](../../releases) page.
2. Double-click `transistor.apworld` (or place it in `Archipelago/custom_worlds/`).
3. Extract the client mod files into your Transistor `x64` installation folder.
4. Edit `archipelago_config.txt` with your server address, port, and slot name.

## Instalación Rápida

1. Descarga **`transistor.apworld`** y **`TransistorArchipelago-Client.zip`** desde la página [Releases](../../releases).

4. Edita `archipelago_config.txt` con la dirección de servidor, puerto y nombre de ranura.
